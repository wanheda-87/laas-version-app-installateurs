Installateurs LaaS version app — bibliothèque locale hors ligne.

Fichiers joints :
- setup.exe : installation Windows, double-clic, application incluse.
- setup-linux : binaire autonome Linux, application incluse.
- LaaS-Version-App-x86_64.AppImage : cliquable depuis le bureau ; premier clic = installation,
  clics suivants = ouverture de la bibliothèque.
- SHA256SUMS.txt : empreintes des trois fichiers.

Installation en clics : télécharger le fichier correspondant à son système, le lancer,
laisser les emplacements préremplis, choisir 1 à 3 comptes, puis noter les mots de passe.
Le raccourci créé ouvre directement l'interface existante : connexion, régions, étagères,
poches, import de documents, recherche, lecture et thèmes.

Aucun réseau, aucun port, aucun serveur et aucun compte en ligne ne sont nécessaires.
Le transcodage vidéo et la console d'administration sont exclus.
