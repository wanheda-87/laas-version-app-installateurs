Installateurs LaaS version app.

Fichiers joints :
- setup.exe : installation Windows, double-clic.
- setup-linux : binaire autonome Linux.
- LaaS-Version-App-x86_64.AppImage : version Linux cliquable depuis le bureau.
- SHA256SUMS.txt : empreintes des trois fichiers.

Installation en clics : télécharger le fichier correspondant à son système, le lancer,
laisser les emplacements préremplis, choisir 1 à 3 comptes, puis noter les mots de passe.
Aucun réseau, aucun serveur et aucun compte en ligne ne sont nécessaires.

Limite : ces installateurs créent la bibliothèque vide et le raccourci. L'interface de
l'application n'est pas encore livrée dans ce paquet ; le raccourci affiche un message clair
tant que le binaire de l'application n'existe pas.
